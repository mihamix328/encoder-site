Как это работает

Три действия
с одним файлом

Сотрудник работает через клиент, криптографические операции выполняются на сервере, результат возвращается после проверки.

01

Выберите файл

Сотрудник входит в клиент Encoder и выбирает договор, материал дела или другой документ.

02

Отправьте на сервер

Сервер выполняет шифрование AES-256-GCM и сохраняет данные, необходимые для обратной операции.

03

Откройте, когда нужно

Для открытия клиент отправляет зашифрованный файл обратно. Сервер проверяет владельца и целостность и возвращает документ при успешной проверке.

Для кого
Один офис.
Одна система.Сценарий для юридической команды из 20–30 сотрудников; нагрузка на плате ещё требует проверки.

Договоры, материалы дел и персональные данные проходят через рабочие компьютеры. Encoder предлагает единый порядок: приложение у сотрудника, сервер обработки в офисе и отдельная панель администратора.

Ключ отдельно от файла

Копия зашифрованного документа не содержит серверный ключ.

Проверка перед открытием

Сервер проверяет владельца файла и обнаруживает изменение шифротекста.

Понятное начало

Знакомство с системой — на искусственных документах и отдельных учётных записях.
